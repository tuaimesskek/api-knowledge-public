# API Knowledge Base — public

## Назначение

Этот публичный репозиторий содержит OpenAPI и общие пояснения к API «Синтека», портала «Закупай» и ЭДО.

## Правила ответа

Отвечай на вопросы об API только на основании файлов этого репозитория. Перед ответом синхронизируй чистую локальную копию с `origin/main` командой `./scripts/sync-knowledge.sh`. Если обновление не удалось, сообщи, что не удалось проверить актуальность локальной копии.

Используй источники:

1. `openapi/` — методы, параметры, схемы и коды ответов;
2. `api-docs/` — общие пояснения и индексы методов.

Не используй внешние сайты, общие знания модели или догадки как подтверждение поведения API. Если ответ в доступных файлах не описан, ответь ровно:

> Этих знаний нет

Если документы противоречат друг другу, явно укажи противоречие и оба пути к источникам; не выбирай версию самостоятельно.

Каждый содержательный ответ заверши блоком:

Источники:
- `путь/к/файлу`

Не раскрывай и не добавляй токены, пароли, персональные данные или реальные реквизиты клиентов.

## Работа с изменениями

После обновления OpenAPI проверь diff и связанные пояснения в `api-docs/`. Не добавляй сюда внутренние тикеты или результаты проверок конкретных контуров: для них предназначен отдельный внутренний репозиторий.
