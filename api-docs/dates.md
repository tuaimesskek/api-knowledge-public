# Даты и часовые пояса

API поддерживает ISO 8601 и Unix time.

При передаче ISO 8601 поддерживаются, в частности, форматы:

- `yyyy-MM-dd HH:mm:ss`;
- `yyyy-MM-ddTHH:mm:ss`;
- `yyyy-MM-dd HH:mm`;
- `yyyy-MM-ddTHH:mm`;
- `yyyy-MM-dd`.

Unix time может передаваться в секундах или миллисекундах от Unix epoch по UTC.

В ответах по умолчанию используется Unix time в миллисекундах. Для ISO 8601 используется GET-параметр `isoDate`.

Если часовой пояс не указан, ISO-дата интерпретируется по московскому времени согласно опубликованному описанию API. Для интеграций из другого часового пояса передавайте часовой пояс явно или используйте Unix time.

Источник: `openapi/swagger-core.yaml`, описание API.
