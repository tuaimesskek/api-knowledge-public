# Ошибки и общий формат ответа

Успешный ответ обычно имеет HTTP-код `200 OK`.

В опубликованном описании указаны, среди прочих, коды:

- `400 Bad Request`;
- `401 Unauthorized`;
- `403 Forbidden`;
- `404 Not Found`;
- `500 Internal Server Error`.

В общем ответе могут присутствовать:

- `result` — признак успешности;
- `errorMessage` — сообщение об ошибке;
- `errors` — подробности ошибок с полем `path`.

Наличие конкретного кода и тела ответа нужно проверять в описании соответствующего метода.

Источник: `openapi/swagger-core.yaml`, описание API.
