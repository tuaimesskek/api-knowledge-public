# Форматы ответа

По умолчанию API возвращает JSON.

XML можно запросить:

- GET-параметром `format=xml`;
- заголовком `Accept: text/xml`;
- заголовком `Accept: application/xml`.

Если значение `Accept` не поддерживается, используется значение GET-параметра. Некорректные значения в итоге приводят к JSON.

Источник: `openapi/swagger-core.yaml`, описание API.
