# Окружения и адреса

В опубликованном OpenAPI указаны адреса и примеры для разных типов интеграций. Конкретный base URL зависит от окружения и типа интеграции; сверяйтесь с актуальным описанием в `openapi/`.

Не подставляйте адрес из примера в рабочие запросы без проверки, что он предназначен для нужного окружения.

Источник: `openapi/swagger-core.yaml` и `openapi/swagger-edi.yaml`.
