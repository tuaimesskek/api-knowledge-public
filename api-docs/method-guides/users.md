# Пользователи

Методы этого раздела сгруппированы по назначению. Для каждого метода указаны контрактные сведения из Swagger; поля и ограничения, которых нет в спецификации, здесь не предполагаются.

Источники:

- `openapi/swagger-core.yaml`

## `POST /api/v1/persons/createWithExternalId`

**Название в Swagger:** Создание пользователя с внешним ID.

**Описание Swagger:**

Пользователь, пытающийся создать пользователя, должен иметь право REFBOOKS_CONTACTS_CREATE_WITH_EXTERNAL_ID. Метод позволяет клиенту перенести пользовалей из своей информационной системы на портал «Закупай», при этом сохранив привязку по своему внутреннему ID. Сразу после создания пользователь может выполнять вход на портал «Закупай» с логином и паролем, которые были заданы при создании.

### Параметры

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| query | `format` | Нет | string | Возможность задать формат ответа API через `GET` параметр.<br>Любые недопустимые значения параметра игнорируются и используется<br>`json` (см. [Формат ответа](#response-format)). |
| query | `isoDate` | Нет | string | Возможность задать формат представления дат в ответе API как *ISO 8601*.<br>Любые значения параметра игнорируются, необходимо лишь наличие параметра<br>(см. [Формат представления дат](#date-format)). |
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений, интегрированных с порталом". |

### Тело запроса

Обязательность тела явно не указана.

Формат: `application/json`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `email` | Да | string | Email пользователя, который станет логином пользователя. Заданный email не должен быть занят на портале «Закупай». Максимальная допустимая длина 256 символов. |
| `password` | Да | string | Пароль пользователя. Должен отвечать требованию к паролю - минимум 8 символов при этом 6 из них уникальные. |
| `lastName` | Да | string | Фамилия пользователя. Максимальная допустимая длина 256 символов. |
| `firstName` | Нет | boolean | Имя пользователя. Максимальная допустимая длина 256 символов. |
| `middleName` | Нет | string | Отчетство пользователя. Максимальная допустимая длина 256 символов. |
| `sex` | Нет | string | Пол пользователя. (MALE/FEMALE) |
| `title` | Нет | string | Должность пользователя. Максимальная допустимая длина 256 символов. |
| `birthDate` | Нет | string | Дата рождения пользователя. В формате ISO 8601 (см. [Формат представления дат](#date-format)). |
| `externalId` | Да | string | Внешний ID пользователя. В дальнейшем по этому ID возможно выполнять операции над пользователем. Внешний ID должен быть уникальным в рамках всей иерархии компании, которой принадлежит пользователь, выполняющий запрос. Максимальная допустимая длина 512 символов. |
| `spot` | Да | object | Адрес компании пользователя. Для получения адресов компании обратитесь в техподдержку портала «Закупай». |
| `phoneNumbers` | Да | array | Контактные телефоны пользователя. |
| `emailType` | Да | object | Тип email |

### Успешный ответ

Swagger описывает успешный ответ `200`.

Формат: `application/json`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `result` | Да | boolean | Запрос завершился успешно |

### Ошибки и другие ответы

- `400` — Bad Request
- `401` — Unauthorized
- `403` — Forbidden
- `404` — Not Found
- `500` — Internal Server Error
