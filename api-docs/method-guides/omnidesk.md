Методы этого раздела сгруппированы по назначению. Для каждого метода указаны контрактные сведения из Swagger; поля и ограничения, которых нет в спецификации, здесь не предполагаются.

Источники:

- `openapi/swagger-core.yaml`

## Кратко по методам

| Метод | Для чего | Как указать объект и данные | Что меняет / возвращает |
|---|---|---|---|
| `POST`<br>`/api/v1/omnidesk/createTicket` | Создание обращения в Омнидеск | В query: параметры формата ответа/дат. В теле: `subject`, `content`, `contentHtml`, `files`. Заголовок: `ZakupayToken`. | Выполняет действие «создание обращения в омнидеск». Данные: Тема обращения (`subject`); Содержание обращения (`content`); HTML-содержание обращения (`contentHtml`); Файлы, приложенные к обращению (`files`). Ответ: `result`, `omnideskResponse`. |

## `POST /api/v1/omnidesk/createTicket`

**Название в Swagger:** Создание обращения в Омнидеск.

**Описание Swagger:**

Создание обращения в Омнидеск. Тело запроса должно содержать тему обращения, а также текстовое либо html-содержание обращения. При необходимости к обращению можно прикрепить файлы общим размером не более 28 Мб, максимальный размер одного файла 25 Мб.


Пользователь, создающий обращение, должен быть авторизован и иметь действительный адрес электронной почты или номер телефона.

При создании обращения автоматически проставляется метка "1С".

### Параметры

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| query | `format` | Нет | string | Возможность задать формат ответа API через `GET` параметр. Любые недопустимые значения параметра игнорируются и используется `json` (см. [Формат ответа](#response-format)). |
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном  кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений,  интегрированных с порталом". |

### Тело запроса

Обязательность тела явно не указана.

Формат: `application/json`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `subject` | Да | string | Тема обращения. Обязательное поле |
| `content` | Да | string | Содержание обращения. Обязательное поле, если нет HTML-содержания. |
| `contentHtml` | Да | string | HTML-содержание обращения. Имеет больший приоритет, чем текстовое содержание. Обязательное поле, если нет текстового содержания. |
| `files` | Нет | array | Файлы, приложенные к обращению.<br> Файлы нужно загрузить предварительно до создания обращения и получить их `Id`. Для загрузки файлов используйте метод API *"Загрузка файлов"* из раздела *"Утилиты"*. |

### Успешный ответ

Swagger описывает успешный ответ `201`.

Формат: `application/json`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `result` | Нет | boolean | Запрос завершился успешно, обращение создано |
| `omnideskResponse` | Нет | object |  |

### Ошибки и другие ответы

- `400` — Bad Request
- `404` — Not Found
- `500` — Internal Server Error
