Источники:

- `openapi/swagger-core.yaml`

## `GET /api/v1/offers`

**Название в Swagger:** Получение информации по счетам (заказчик).

**Описание Swagger:**

Пользователь, пытающийся получить список счетов, должен иметь право `OFFERS` на работу со счетами.

Метод предоставляет возможность запрашивать коллекцию счетов постранично, максимальное количество счетов на странице задается параметром `pageSize` (стандартное значение = **10**, максимальное значение = **100**), для загрузки страниц используется параметр `page`. Также доступны различные способы по фильтрации счетов.

При включенной мультиязычности будут доступны дополнительные поля и названия позиций на разных языках, если это указывалось при создании позиций. Если язык не задан в HTTP запросе, то по умолчанию будет "ru" . Задать язык можно с помощью HTTP-заголовка Accept-Language. Например: Accept-Language: de-DE
