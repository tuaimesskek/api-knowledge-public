# Файлы

Методы этого раздела сгруппированы по назначению. Для каждого метода указаны контрактные сведения из Swagger; поля и ограничения, которых нет в спецификации, здесь не предполагаются.

Источники:

- `openapi/swagger-core.yaml`

## Кратко по методам

| Метод | Для чего | Как указать объект и данные | Что меняет / возвращает |
|---|---|---|---|
| `GET`<br>`/core/companies/files/{fileId}` | Получение файла документа компании | В URL: `fileId` — ID файла. Заголовок: `ZakupayToken`. | Возвращает: `file`. |
| `POST`<br>`/core/files/upload` | Загрузка файла | В query: `type`, `async`, `base64`, …. В теле: `file`. Заголовок: `ZakupayToken`. | Выполняет действие «загрузка файла». Данные: `file`. Ответ: структура успешного ответа не раскрыта. |
| `GET`<br>`/core/deliveries/{deliveryId}/files/{fileId}` | Получение файла доставки | В URL: `deliveryId` — ID доставки; `fileId` — ID файла. Заголовок: `ZakupayToken`. | Возвращает: `file`. |
| `GET`<br>`/core/orders/{orderId}/files/{fileId}` | Получение файла заявкки | В URL: `orderId` — ID заявки; `fileId` — ID файла. Заголовок: `ZakupayToken`. | Возвращает: `file`. |
| `GET`<br>`/api/v1/orders/download/{entityType}/{id}/{type}` | Получение файла заявки | В URL: `entityType` — тип сущности; `id` — ID объекта; `type` — значение `type`. Заголовок: `ZakupayToken`. | Возвращает: `file`. |
| `GET`<br>`/api/v1/offers/files/{fileId}` | Получение файла счета | В URL: `fileId` — ID файла. Заголовок: `ZakupayToken`. | Возвращает: `file`. |
| `GET`<br>`/core/offers/{offerId}/approvalSheet` | Получение файла листа согласования счета | В URL: `offerId` — ID счёта. Заголовок: `ZakupayToken`. | Возвращает: `file`. |

Подробные параметры, поля, ответы и ошибки для каждого метода — ниже.

## `GET /core/companies/files/{fileId}`

**Название в Swagger:** Получение файла документа компании.

**Описание Swagger:**

__Метод доступен если   пользователь__:

        - авторизован;

        - имеет доступ к системе;

        - состоит в какой-либо компании;

        - имеет право `REFBOOKS_COMPANY_DOCUMENTS`;

### Параметры

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| path | `fileId` | Да | number | Идентификатор файла документа компании |
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений, интегрированных с порталом". |

### Успешный ответ

Swagger описывает успешный ответ `200`.

Формат: `multipart/form-data`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `file` | Да | string[binary] |  |

### Ошибки и другие ответы

- `400` — Bad Request
- `401` — Unauthorized
- `403` — Forbidden
- `404` — Not Found
- `500` — Internal Server Error


## `POST /core/files/upload`

**Название в Swagger:** Загрузка файла.

**Описание Swagger:**

__Метод доступен если пользователь__:

        - авторизован;

        - имеет доступ к системе;

__Если название файла слишком длинное, то оно будет обрезано при сохранении.__

### Параметры

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| query | `format` | Нет | string | Возможность задать формат ответа API через `GET` параметр.<br>Любые недопустимые значения параметра игнорируются и используется<br>`json` (см. [Формат ответа](#response-format)). |
| query | `type` | Нет | string | Возможность задать тип загрузки файла |
| query | `async` | Нет | string | Возможность выпонять загрузку файла асинхронно |
| query | `base64` | Нет | string | Возможностьзадать контекст Base64 |
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений, интегрированных с порталом". |

### Тело запроса

Обязательность тела явно не указана.

Формат: `multipart/form-data`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `file` | Да | string[binary] |  |

### Успешный ответ

Swagger описывает успешный ответ `200`.

Формат: `application/json`.

Структура успешного ответа не раскрыта на верхнем уровне операции.

### Ошибки и другие ответы

- `400` — Bad Request
- `401` — Unauthorized
- `403` — Forbidden
- `404` — Not Found
- `500` — Internal Server Error

## `GET /api/v1/orders/download/{entityType}/{id}/{type}`

**Название в Swagger:** Получение файла заявки.

**Описание Swagger:**

Позволяет получить файл заявки (ORDER), файл заявки+лист согласования (ORDER_ACCEPT), файл заявки+лист согласования+чат (ORDER_ACCEPT_CHAT), согласно заданному типу, указанному в круглых скобках

__Метод доступен если пользователь__:

      - авторизован;

      - имеет доступ к системе;

      - подходит под описание выше;

### Параметры

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| path | `id` | Да | integer[int64] | Идентификатор заявки |
| path | `type` | Да | string | Тип скачиваемого документа |
| path | `entityType` | Да | string | Сущность, id которой передается (ORDER, OFFER, UTD) |
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений, интегрированных с порталом". |

### Успешный ответ

Swagger описывает успешный ответ `200`.

Формат: `multipart/form-data`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `file` | Да | string[binary] |  |

### Ошибки и другие ответы

- `400` — Bad Request
- `401` — Unauthorized
- `403` — Forbidden
- `404` — Not Found
- `500` — Internal Server Error
