# Товарные категории

Методы этого раздела сгруппированы по назначению. Для каждого метода указаны контрактные сведения из Swagger; поля и ограничения, которых нет в спецификации, здесь не предполагаются.

Источники:

- `openapi/swagger-core.yaml`

## Кратко по методам

| Метод | Для чего | Как указать объект и данные | Что меняет / возвращает |
|---|---|---|---|
| `GET`<br>`/api/v1/refbooks/categories` | Справочник товарных категорий | В query: `withInactive`, …. Заголовок: `ZakupayToken`. | Возвращает: `result`, `categories`. |
| `POST`<br>`/api/v1/refbooks/categories` | Создание товарной категории | В теле: `name`, `externalId`, `active`, `assignable`, `minTerm`, `parent`, …. Заголовок: `ZakupayToken`. | Выполняет действие «создание товарной категории». Данные: Название товарной категории (`name`); Внешний Id номенклатуры (`externalId`); активна ли товарная категория (`active`); `assignable`; `minTerm`; …. Ответ: `result`, `categoryTypes`. |
| `PUT`<br>`/api/v1/refbooks/categories/:{id}/{externalId}` | Создание товарной категории | В URL: `id` — ID объекта; `externalId` — внешний ID. В теле: `name`, `externalId`, `active`, `assignable`, `minTerm`, `parent`, …. Заголовок: `ZakupayToken`. | Обновляет: Название товарной категории (`name`); Внешний Id номенклатуры (`externalId`); активна ли товарная категория (`active`); `assignable`; `minTerm`; …. Ответ: `result`, `categoryTypes`. |
| `GET`<br>`/api/v1/refbooks/allCategoryTypes` | Типы товарных категорий | Заголовок: `ZakupayToken`. | Выполняет действие «типы товарных категорий». Ответ: `result`, `categoryTypes`. |

Подробные параметры, поля, ответы и ошибки для каждого метода — ниже.

## `GET /api/v1/refbooks/categories`

**Название в Swagger:** Справочник товарных категорий.

**Описание Swagger:**

Метод позволяет получить информацию по справочнику **"Товарные категории"**.
 Товарные категории представляют собой древовидную структуру, которую на клиенте необходимо будет восстановить

### Параметры

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| query | `format` | Нет | string | Возможность задать формат ответа API через `GET` параметр. Любые недопустимые значения параметра игнорируются и используется `json` (см. [Формат ответа](#response-format)). |
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений, интегрированных с порталом". |
| query | `withInactive` | Нет | boolean | Отвечает на вопрос - возвращать товарные категории включая неактивные? |

### Успешный ответ

Swagger описывает успешный ответ `200`.

Формат: `application/json`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `result` | Да | boolean | Запрос завершился успешно. |
| `categories` | Да | array | Коллекция товарных категорий. |

### Ошибки и другие ответы

- `400` — Bad Request
- `401` — Unauthorized
- `403` — Forbidden
- `404` — Not Found
- `500` — Internal Server Error


## `POST /api/v1/refbooks/categories`

**Название в Swagger:** Создание товарной категории.

**Описание Swagger:**

Создание товарной категории

### Параметры

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном  кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений,  интегрированных с порталом". |

### Тело запроса

Обязательность тела явно не указана.

Формат: `application/json`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `name` | Нет | string | Название товарной категории |
| `externalId` | Нет | string | Внешний Id номенклатуры. |
| `active` | Нет | boolean | активна ли товарная категория |
| `assignable` | Нет | boolean | Можно ли относить позиции к товарной категории |
| `minTerm` | Нет | integer | Минимальный срок в днях заказа позиции по товарной категории |
| `parent` | Нет | integer | Родительская товарная категория |
| `categoryType` | Нет | integer | Тип товарной категории |
| `isDelivery` | Нет | boolean | Является ли товарная категория доставкой |

### Успешный ответ

Swagger описывает успешный ответ `200`.

Формат: `application/json`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `result` | Да | boolean | Запрос завершился успешно. |
| `categoryTypes` | Да | array | Типы товарных категорий. |

### Ошибки и другие ответы

- `401` — Unauthorized
- `500` — Internal Server Error
