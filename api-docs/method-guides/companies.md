# Компании

Методы этого раздела сгруппированы по назначению. Для каждого метода указаны контрактные сведения из Swagger; поля и ограничения, которых нет в спецификации, здесь не предполагаются.

Источники:

- `openapi/swagger-core.yaml`

## Кратко по методам

| Метод | Для чего | Как указать объект и данные | Что меняет / возвращает |
|---|---|---|---|
| `GET`<br>`/api/v1/company` | Поиск компаний | В query: `id`, `name`, `shortName`, `inn`, `kpp`, …. Заголовок: `ZakupayToken`. | Возвращает: `result`, `data`. |
| `GET`<br>`/api/v1/company/{id}/requisites` | Выгрузка реквизитов компании | В URL: `id` — ID компании. Заголовок: `ZakupayToken`. | Возвращает: `string (поля в Swagger не раскрыты)`. |
| `GET`<br>`/api/v1/company/documents` | Получение информации по документам компаний | В query: `page`, `pageSize`, `companyInn`, …. | Возвращает: `result`, `data`. |
| `POST`<br>`/api/v1/company/documents` | Создание/обновление документов компании | В query: параметры формата ответа/дат. В теле: `id`, `documents`. Заголовок: `ZakupayToken`. | Выполняет действие «создание/обновление документов компании». Данные: Идентификатор компани, для которой будет создан документ (`id`); Список документов, которые будут сохранены (`documents`). Ответ: `result`, `company`. |
| `POST`<br>`/api/v1/company/tag` | Добавить/отменить ярлык на компанию | В query: параметры формата ответа/дат. В теле: `inn`, `kpp`, `tagId`, `isRemove`. Заголовок: `ZakupayToken`. | Выполняет действие «добавить/отменить ярлык на компанию». Данные: ИНН компании (`inn`); КПП компании (не узказывается при отсутствии) (`kpp`); ID тэга в системе (`tagId`); Является ли операция отменой пометки тэгом (`isRemove`). Ответ: `result`. |
| `GET`<br>`/api/v1/company/documents/{companyDocumentId}/specification` | Получить позиции спецификации документа компании | В URL: `companyDocumentId` — ID документа компании. В query: параметры формата ответа/дат. Заголовок: `ZakupayToken`. | Возвращает: `result`, `specification_items`. |

Подробные параметры, поля, ответы и ошибки для каждого метода — ниже.

## `GET /api/v1/company`

**Название в Swagger:** Поиск компаний.

**Описание Swagger:**

Поиск компаний. Заданные фильтры применяются совместно (логическое И).
Если найдено несколько компаний, возвращаются все (с постраничной нарезкой).
Если совпадений нет, возвращается пустой список.

__Метод доступен если пользователь__:

        - авторизован;

        - имеет доступ к системе;

        - состоит в какой-либо компании;

        - имеет право `REFBOOKS_COMPANIES`;

        - запрос выполняется к коробке (не к порталу).

### Параметры

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| query | `format` | Нет | string | Возможность задать формат ответа API через `GET` параметр. Любые недопустимые значения параметра игнорируются и используется `json` (см. [Формат ответа](#response-format)). |
| query | `id` | Нет | integer[int64] | Идентификатор компании. Точное совпадение с `company.id`. Можно передать несколько значений (`id=1&id=2`). |
| query | `name` | Нет | string | Частичное совпадение с полным наименованием компании, без учёта регистра. |
| query | `shortName` | Нет | string | Частичное совпадение с кратким наименованием компании, без учёта регистра. |
| query | `inn` | Нет | string | Точное совпадение с ИНН компании. |
| query | `kpp` | Нет | string | Точное совпадение с КПП компании. |
| query | `ogrn` | Нет | string | Точное совпадение с ОГРН компании. |
| query | `email` | Нет | string | Точное совпадение с email компании, без учёта регистра. |
| query | `page` | Нет | number | Номер страницы, данные с которой нужно вернуть. Если не задан, то по умолчанию будет возвращена первая страница данных. |
| query | `pageSize` | Нет | number | Размер страницы. Максимальное значение 100. Если не задано или задано некорректно, то будет принято как 10 или 100 в зависимости от ситуации. |
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений, интегрированных с порталом". |

### Успешный ответ

Swagger описывает успешный ответ `200`.

Формат: `application/json`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `result` | Да | boolean | Запрос завершился успешно. |
| `data` | Да | object | Полученные данные |

### Ошибки и другие ответы

- `400` — Bad Request
- `401` — Unauthorized
- `403` — Forbidden
- `500` — Internal Server Error


## `GET /api/v1/company/{id}/requisites`

**Название в Swagger:** Выгрузка реквизитов компании.

**Описание Swagger:**

Метод позволяет получить реквизиты компании в формате `xlsx`.


 __Метод доступен если__:

    - Пользователь авторизован;

    - Пользователь имеет доступ к системе;

    - Компания с указанным идентификатором должна существовать;

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| path | `id` | Да | number | идентификатор компании |

### Успешный ответ

Swagger описывает успешный ответ `200`.

Формат: `application/pdf`.

Тип ответа: `string`.

### Ошибки и другие ответы

- `400` — Bad Request
- `401` — Unauthorized
- `403` — Forbidden
- `500` — Internal Server Error

Метод позволяет получить позиции спецификации документа компании. Если все позиции спецификации удалены, то вернёт пустой массив.

        - авторизован;

        - имеет доступ к системе;

        - состоит в какой-либо компании;

        - имеет право `REFBOOKS_COMPANY_DOCUMENTS`;

### Параметры

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| query | `format` | Нет | string | Возможность задать формат ответа API через `GET` параметр.<br>Любые недопустимые значения параметра игнорируются и используется<br>`json` (см. [Формат ответа](#response-format)). |
| path | `companyDocumentId` | Да | string | Идентификатор документа компании |
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений, интегрированных с порталом". |

### Успешный ответ

Swagger описывает успешный ответ `200`.

Формат: `application/json`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `result` | Да | boolean | Запрос завершился успешно |
