# Номенклатура

Методы этого раздела сгруппированы по назначению. Для каждого метода указаны контрактные сведения из Swagger; поля и ограничения, которых нет в спецификации, здесь не предполагаются.

Источники:

- `openapi/swagger-core.yaml`

## `POST /api/v1/nomenclatures`

**Название в Swagger:** Создание номенклатуры.

**Описание Swagger:**

Создание номенклатуры. Метод для создания новой позиции товарной базы.

  __Метод доступен если пользователь__:

        - авторизован;

        - имеет доступ к системе;

        - состоит в какой-либо компании;

        - имеет право `GOOD_BASE_ITEM_CREATE`;

### Параметры

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| query | `format` | Нет | string | Возможность задать формат ответа API через `GET` параметр. Любые недопустимые значения параметра игнорируются и используется `json` (см. [Формат ответа](#response-format)). |
| query | `isoDate` | Нет | string | Возможность задать формат представления дат в ответе API как **ISO 8601**. Любые значения параметра игнорируются, необходимо лишь наличие параметра (см. [Формат представления дат](#date-format)). |
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном  кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений,  интегрированных с порталом". |

### Тело запроса

Обязательность тела явно не указана.

Формат: `application/json`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `name` | Да | string | Название номенклатуры. Обязательное поле |
| `externalId` | Нет | string | Внешний Id номенклатуры. |
| `category` | Нет | object | Товарная категория. |
| `unit` | Нет | object | Единица измерения. |

### Успешный ответ

Swagger описывает успешный ответ `200`.

Формат: `application/json`.

Тип ответа: `object`.

### Ошибки и другие ответы

- `400` — Bad Request
- `404` — Not Found
- `500` — Internal Server Error
