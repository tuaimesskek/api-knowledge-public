# Справочники

Методы этого раздела сгруппированы по назначению. Для каждого метода указаны контрактные сведения из Swagger; поля и ограничения, которых нет в спецификации, здесь не предполагаются.

Источники:

- `openapi/swagger-core.yaml`
- `openapi/swagger-edi.yaml`

## `GET /api/v1/refbooks/good-positions`

**Название в Swagger:** Справочник товарной базы.

**Описание Swagger:**

Метод позволяет получить товарную базу.

### Параметры

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений, интегрированных с порталом". |
| query | `id` | Нет | integer[int64] | Возможность указать id для поиска конкретной позиции товарной базы. |
| query | `externalId` | Нет | string | Возможность указать externalId для поиска конкретной позиции товарной базы. |
| query | `page` | Нет | integer[int64] | Возможность указать страницу (по умолчанию 1). |
| query | `limit` | Нет | integer[int64] | Возможность указать количество позиций на странице (по умолчанию 15). |

### Успешный ответ

Swagger описывает успешный ответ `200`.

Формат: `application/json`.

Тип ответа: `array`.

### Ошибки и другие ответы

- `500` — Internal Server Error

## `GET /api/v1/refbooks/employees/{inn}`

**Название в Swagger:** Список сотрудников по ИНН компании.

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| path | `inn` | Да | string | ИНН компании. |
| query | `fullName` | Нет | string | Поиск сотрудника по ФИО без учёта регистра.<br><br>Формат значения:<br><br>  - фамилия: `Иванов`<br><br>  - фамилия и первая буква имени через пробел: `Иванов И`<br><br>  - фамилия и имя: `Иванов Иван`<br><br>Точки в инициалах не ставьте (`Иванов И`, не `Иванов И.`).<br>Если параметр не передан, фильтрация по ФИО не применяется.<br>Если совпадений несколько, возвращаются все найденные сотрудники.<br>Если совпадений нет, возвращается пустой список. |
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений, интегрированных с порталом". |
