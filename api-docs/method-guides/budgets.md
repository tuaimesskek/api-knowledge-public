# Бюджеты

Методы этого раздела сгруппированы по назначению. Для каждого метода указаны контрактные сведения из Swagger; поля и ограничения, которых нет в спецификации, здесь не предполагаются.

Источники:

- `openapi/swagger-core.yaml`

## Кратко по методам

| Метод | Для чего | Как указать объект и данные | Что меняет / возвращает |
|---|---|---|---|
| `POST`<br>`/core/budgets/save` | Метод сохраняет новый бюджет или обновляет текущий __Метод доступен если__: пользователь - авторизован; - имеет право BUDGET (входит во все стандартные роли сотрудников); | В теле: `baseBudget`, `budgetItems`, `creationDate`, `excelTemplate`, `id`, `isFromInterface`, …. Заголовок: `ZakupayToken`. | Выполняет действие «метод сохраняет новый бюджет или обновляет текущий __метод доступен если__: пользователь - авторизован; - имеет право budget (входит во все стандартные роли сотрудников);». Данные: `baseBudget`; Информация по позициям бюджета: (`budgetItems`); `creationDate`; Шаблон таблицы excel (`excelTemplate`); Идентификатор бюджета (`id`); …. Ответ: `result`, `budget`. |

Подробные параметры, поля, ответы и ошибки для каждого метода — ниже.

## `POST /core/budgets/save`

**Название в Swagger:** Метод без названия в OpenAPI.

**Описание Swagger:**

Метод сохраняет новый бюджет или обновляет текущий

__Метод доступен если__:
пользователь

    - авторизован;

    - имеет право BUDGET (входит во все стандартные роли сотрудников);

### Параметры

| Где | Имя | Обязательный | Тип | Описание |
|---|---|---:|---|---|
| header | `ZakupayToken` | Да | string | Токен для авторизации пользователя в системе, значение которого можно получить в личном кабинете пользователя на вкладке "Безопасность" в разделе "Токены для приложений, интегрированных с порталом". |

### Тело запроса

Обязательность тела явно не указана.

Формат: `application/json`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `baseBudget` | Нет | object |  |
| `budgetItems` | Нет | array | Информация по позициям бюджета: |
| `creationDate` | Нет | number | Время создания позиции в `UNIX` или `ISO 8601` - формате |
| `excelTemplate` | Нет | object | Шаблон таблицы excel |
| `id` | Нет | integer[int64] | Идентификатор бюджета |
| `isFromInterface` | Нет | boolean | Запрос был отправлен из приложения cynteka? (Нужно проставить `false`) |
| `locked` | Нет | boolean | Бюджет заблокирован для изменений? (если да, то его изменение возможно лишь с правом `BUDGET_ASSIGNABLE_COLUMN`) |
| `name` | Нет | string | Название бюджета |
| `project` | Да | object | Проект текущего бюджета |
| `projectAmount` | Нет | number | Стоимость проекта |

### Успешный ответ

Swagger описывает успешный ответ `200`.

Формат: `application/json`.

| Поле | Обязательное | Тип | Описание |
|---|---:|---|---|
| `result` | Нет | boolean | Запрос завершился успешно |
| `budget` | Нет | object |  |

### Ошибки и другие ответы

- `400` — Bad Request
- `401` — Unauthorized
- `403` — Forbidden
- `500` — Internal Server Error
