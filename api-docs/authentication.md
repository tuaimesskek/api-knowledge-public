# Аутентификация и авторизация

В опубликованном OpenAPI для аутентификации используется HTTP-заголовок `ZakupayToken`.

Наличие токена само по себе не подтверждает наличие прав на конкретную операцию: проверяйте требования соответствующего метода в OpenAPI.

Используйте только HTTPS. Не записывайте реальные токены в примеры или Git.

Источник: `openapi/swagger-core.yaml`, описание API.
