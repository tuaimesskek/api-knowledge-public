# Политика источников

## OpenAPI

Используйте опубликованный OpenAPI для ответов о контракте:

- существование endpoint;
- HTTP-метод и путь;
- параметры и обязательность полей;
- схемы запросов и ответов;
- описанные коды ответов.

## Пояснения и индексы

Используйте `api-docs/` для кратких пояснений к опубликованной спецификации и поиска методов. Если пояснение расходится с OpenAPI, сообщите об этом и укажите оба файла; не исправляйте противоречие догадкой.

## Ограничения публичной копии

Репозиторий содержит только опубликованную спецификацию и общие пояснения. Он не устанавливает фактическое поведение конкретного клиента или окружения и может не содержать практических сведений, которых нет в OpenAPI.
