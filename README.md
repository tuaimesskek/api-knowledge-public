# API Knowledge Base — public

Публичная справочная копия OpenAPI для API «Синтека», портала «Закупай» и ЭДО.

## Использование в Codex

Клонируйте репозиторий и откройте его корневую папку в Codex. Задавайте вопросы по API обычным языком. Codex должен отвечать по материалам репозитория и указывать пути к файлам источников.

```bash
git clone https://github.com/tuaimesskek/api-knowledge-public.git
```

Для обновления локальной копии выполните `git pull` или попросите Codex синхронизировать её с GitHub.

## Содержимое

- `openapi/swagger-core.yaml` — опубликованная спецификация основного API;
- `openapi/swagger-edi.yaml` — опубликованная спецификация ЭДО API;
- `api-docs/` — пояснения и индексы методов, а также обобщённые практические сведения, например о частоте запросов, с указанием их источников и ограничений.

Это публичная справочная копия опубликованной спецификации и обобщённых сведений поддержки. Здесь нет внутренних карточек тикетов, их номеров и отчётов о проверках конкретных клиентских или тестовых контуров. Практические детали, не описанные в опубликованном контракте, могут отсутствовать; для них указаны источник и границы подтверждения.

## Обновление OpenAPI

Получить опубликованные версии спецификаций можно командой:

```bash
./scripts/update-openapi.sh
```

После обновления проверьте `git diff`, затем отправьте изменения в репозиторий.

## Безопасность

Не добавляйте в репозиторий токены, пароли, персональные данные, реальные клиентские реквизиты, внутренние тикеты или результаты проверок конкретных стендов.
